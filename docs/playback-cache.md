# 播放缓存

播放磁盘缓存默认关闭；在设置中将上限设置为 128–4096 MiB 可开启，设为 0 会关闭并删除已有播放磁盘缓存。数据存放于应用数据目录下 `playback-cache`，重启后保留。清理缓存也会删除磁盘播放缓存，收藏、历史与登录状态保留。关闭磁盘缓存时，播放器继续使用原有的内存缓冲。

后台只有一个下载槽，点播 HLS 的独立分片及字节范围分片按清单顺序预取，使用完整 URL 和字节范围区分缓存块；单个块超过 16 MiB 时不预取，播放器继续按需联网。原生 HLS 对多清晰度清单跟随播放器实际请求的清晰度；直播不预取。已选独立音轨、当前开启的字幕轨、解密密钥和初始化片段纳入同一预取队列；关闭字幕时停止字幕预取；播放中途重新开启时，优先加载当前位置的字幕段，再向后预取，已经播放过的字幕段不补下载，已有字幕块直接复用。切换音轨或字幕语言时取消旧任务并拒绝旧轨道迟到的清单。内嵌音频和字幕随原有媒体块一起缓存。直接媒体按 1 MiB 字节块预取，只在上游支持字节范围并提供强 ETag 时启用，ETag 变化后不会与旧块混用；不满足条件或播放器未发送 Range 时继续通过原有网络路径播放。对于未知扩展名的播放地址，仍按原有 HLS 路径处理。

空间不足时按最近最少访问淘汰，保护当前播放位置之后已缓存的分片；无法腾出空间时暂停预取。拖动会取消旧预取、优先处理新位置；直接文件根据播放器后续范围请求的位置调整，不以时间比例估算字节位置。缓存上限不包含播放器及 WebView 内存缓冲、下载中的数据或其他应用数据。

进度条淡色部分表示已缓存到磁盘或播放器报告已缓冲的时间范围；直接文件无法可靠地将字节位置换算成播放时间，因此只显示播放器报告的缓冲范围。有独立音轨或开启的独立字幕时，磁盘缓存指示取所选音视频、字幕完整区间的交集，并检查所需密钥与初始化片段；亮色部分为播放进度。完整 URL 的哈希作为缓存键，因此上游更换带签名的地址后不一定复用此前缓存。网络流量可能高于实际观看量；系统播放器缓冲和缓存数据不保证离线观看。

关闭、清理、切集或页面失活会取消排队和进行中的预取。拖动后立即重排，恢复页面时重新检查缓存。单个失败资源最多重试三次，不阻挡其他分片；再次拖动、切换清晰度、恢复页面或更改缓存设置可重新尝试。直接文件完成后不再反复扫描整个文件。

清单与视频分片采用不同有效期：已结束点播主清单缓存 5 分钟，其余主清单 2 秒；子清单不进入分片内存缓存，协议层不缓存清单。启用磁盘缓存时分片响应不再由 WebView 单独长期缓存，以便读取更新 LRU 和清理状态。磁盘索引的访问时间在运行中即时更新，落盘合并到约 5 秒一次及内容写入时。

验证入口：`pnpm test:cache` 覆盖队列、依赖、取消、容量变化和 EOF；`pnpm test:playback --media-dir DIR` 验证真实浏览器播放与时间轴。Rust 的 `media::tests::range_cache_local_server` 需单独允许回环监听后运行，用本地 HTTP 测试范围缓存和动态清单，不访问上游。原生 iOS/macOS 播放仍需实机验证；这些自动测试不等同于原生播放器实测。
