## 1.2.18

### 新增
- **栏目内就地搜索**：各栏目页（吃瓜列表、频道详情、专题 / 专题详情、标签 / 标签视频、关注流、用户主页）顶栏搜索按钮改为**在当前栏目内就地搜索**，不再跳转到全局搜索页。
  - 吃瓜列表搜索走 `type=post`，结果以两列封面墙呈现，点击进帖详情（修复此前吃瓜频道搜索永远为空的问题，#34 #38）。
  - 其余栏目搜索走 `type=video`，结果以视频墙呈现，点击进播放。
  - 全局搜索（底部「搜索」tab）保持只搜短剧，与栏目内搜索彻底分离。

### 修复
- **iOS 诊断报告复制失败（#39）**：此前 iOS 上点「网络诊断」后，先等异步诊断再调 Web Clipboard API，可能被 WebKit 以 NotAllowedError 拒绝。现改为通过 Tauri 官方剪贴板插件写入原生剪贴板，网络报告与播放诊断日志共用同一复制入口；诊断成功但复制失败时保留完整报告并给出独立「复制报告」重试按钮，不重新发起诊断。普通浏览器环境保留 Web Clipboard 回退。

- iOS：未签名 ipa（需自行签名）
